# 🎟️ TixVerse

**TixVerse — Smart Event & Ticket Booking Platform**

A modern, responsive ticket-booking frontend built with HTML, CSS and vanilla JavaScript. It simulates event discovery, filtering, favourites, interactive seat selection, booking confirmation and digital tickets.

## ✨ Features

- Modern responsive UI
- Event discovery by category and city
- Search events
- Price sorting
- Favourite events using localStorage
- Interactive seat selection
- Booking summary with convenience fee
- Demo booking confirmation
- Digital ticket generation
- Booking history stored in localStorage
- Demo sign-in modal
- Light/dark theme toggle
- Mobile-friendly layout

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- LocalStorage
- Google Fonts

## ▶️ Run Locally

No build tools are required.

1. Download or clone the repository.
2. Open the folder in VS Code.
3. Open `index.html` in a browser.

For a better development experience, install the **Live Server** extension in VS Code and choose **Open with Live Server**.

## 🚀 Deploy with GitHub Pages

1. Create a public GitHub repository.
2. Upload the project files.
3. Go to **Settings → Pages**.
4. Under the deployment source, select the `main` branch and `/root`.
5. Save.
6. GitHub will provide the live website URL.

## 🔐 Demo Notice

This project is a frontend portfolio demo. It does **not** process real payments or create real user accounts. Booking and favourites are stored only in the browser's localStorage.
